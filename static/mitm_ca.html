2. Install and trust

iPhone / iPad
  1. Open this page in Safari and tap Download certificate. Tap Allow when asked to download a configuration profile.
  2. Open Settings and tap Profile Downloaded near the top (or Settings → General → VPN & Device Management). Tap the profile, then Install, and enter your passcode.
  3. Turn on full trust — this step is separate and easy to miss:
    Settings → General → About → Certificate Trust Settings, then switch on the RustProxy certificate (named rustproxy MITM CA unless you supplied your own).
  4. Point the device at the proxy: Settings → Wi-Fi → ⓘ next to your network → Configure Proxy → Manual. Server this-host, port {{PROXY_PORT}}.

The Wi-Fi proxy setting on iOS speaks HTTP proxy only, so run rustproxy with --mode http for iPhones and iPads. Apps that pin their certificates will refuse to connect; list their hosts in --mitm-bypass.

To remove: Settings → General → VPN & Device Management → the profile → Remove Profile.

macOS
  1. Download the certificate and double-click rustproxy-ca.crt. Keychain Access opens; add it to the System keychain (or login for just your user).
  2. In Keychain Access, find the certificate (named rustproxy MITM CA unless you supplied your own), double-click it, expand Trust, and set When using this certificate to Always Trust. Close the window and confirm with your password.
  3. Set the proxy: System Settings → Network → your connection → Details → Proxies. Enable Web proxy (HTTP) and Secure web proxy (HTTPS)SOCKS proxy with server this-host, port {{PROXY_PORT}}.

Or from Terminal:

sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain ~/Downloads/rustproxy-ca.crt

Firefox keeps its own certificate store: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import, and tick “Trust this CA to identify websites”.

To remove: delete the certificate in Keychain Access.

Windows
  1. Download the .cer file and double-click it, then choose Install Certificate…
  2. Pick Local Machine (all users, needs administrator) or Current User, then Next.
  3. Select Place all certificates in the following store, click Browse, and choose Trusted Root Certification Authorities. The automatic option puts it in the wrong store.
  4. Finish the wizard and accept the security warning; check that the thumbprint matches the certificate you downloaded.
  5. Set the proxy: Settings → Network & Internet → Proxy → Manual proxy setup. Address this-host, port {{PROXY_PORT}}.

Or from an administrator Command Prompt:

certutil -addstore -f Root "%USERPROFILE%\Downloads\rustproxy-ca.cer"

The Windows proxy setting is an HTTP proxy, so run rustproxy with --mode http. Firefox uses its own store unless security.enterprise_roots.enabled is turned on in about:config.

To remove: run certmgr.msc (or certlm.msc for Local Machine), open Trusted Root Certification Authorities → Certificates, and delete it.

3. Check this device

After installing the certificate and setting the proxy, run this on the device itself. It makes one HTTPS request and asks the proxy what it saw from this device.

Test this device
Only install this on devices you own or are authorised to test. A device that trusts this certificate lets whoever holds the proxy's private key read and alter its HTTPS traffic. Remove the certificate when you are finished.
